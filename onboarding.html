스폰지클럽에 도착했습니다

10분소요
3스텝

설치보다 먼저, 우리 동네 지리부터 익혀요. 슬랙은 매일 만나는 광장이고, 깃허브는 과제를 내는 우체통입니다. 여기서 막히는 분이 의외로 가장 많으니, 천천히 하나씩.

STEP 0-1

슬랙에 입장하고, 이름표를 답니다

슬랙(Slack)은 스폰지클럽의 메인 소통 공간이에요. 7주 동안 공지, 질문, 조별 활동이 모두 여기서 이루어집니다.

1단계: 슬랙 앱 설치

데스크탑과 모바일 모두 설치해 주세요. 알림을 놓치지 않으려면 둘 다 필요합니다.

  • 슬랙 다운로드 페이지

2단계: 초대 링크로 접속

아래 링크를 눌러 스폰지클럽 워크스페이스에 입장하세요.

슬랙 워크스페이스 입장하기 →

3단계: 프로필 설정

프로필과 이름 설정하기

  1. 왼쪽 위 내 프로필 사진 → 프로필 편집
  2. 성명란을 이 형식으로 바꿉니다 → 3기_닉네임(본명) 예: 3기_스펀지(김해면)
  3. 이메일 주소도 함께 설정해 주세요
▶ 프로필 사진 만들기 (클릭해서 펼치기)

gemini.google.com에서 AI 프로필 이미지를 만들 수 있어요.

  1. + 버튼을 눌러서 이미지 만들기 (모델은 사고(thinking) 또는 pro 모델로 설정!)
  2. 본인의 사진과 예시 사진을 넣으면 배경색이 같은 이미지를 생성해줍니다
  3. 스폰지클럽 로고 및 프로필 프레임으로 개성을 뽐내주셔도 좋습니다
프로필 사진은 필수는 아니지만, 있으면 크루들이 서로 알아보기 훨씬 쉬워집니다. 셋업데이 전에 미리 만들어 보세요!

4단계: 인사하기

'인사' 채널에서 간단한 자기소개와 함께 인사를 남겨주세요. 첫 마디가 어려우면 "안녕하세요, 3기 OOO입니다!" 한 줄이면 충분합니다.

슬랙이 처음이어도 부끄러운 일이 아닙니다. 지난 기수에도 처음인 분이 많았어요. 채널 = 주제별 대화방, 이것만 알면 시작할 수 있습니다.

클로드 코드 설치 — AI 동료 채용하기

15분소요
5스텝

오늘 채용하는 AI 동료의 이름은 클로드 코드(Claude Code). 채팅창의 클로드와 달리, 내 컴퓨터 안에서 직접 파일을 만들고 일을 해주는 에이전트입니다. 명령어는 전부 복사 버튼이 있으니 타이핑하지 마세요.

STEP 1-1

터미널을 엽니다

터미널은 "글자로 컴퓨터에게 말 거는 창"입니다. 오늘 이후로는 클로드 코드가 대신 말해줄 테니, 여는 법만 알면 됩니다.

MAC
  1. ⌘ + 스페이스를 눌러 Spotlight를 엽니다
  2. 터미널이라고 입력 → Enter
  3. 흰색(또는 검은색) 창에 커서가 깜빡이면 성공
WINDOWS
  1. 시작 버튼 → cmd 검색
  2. 명령 프롬프트를 클릭 (검은 창)
파란 창(PowerShell)이 열렸다면 닫아주세요. 이 과정은 검은 창 명령 프롬프트(cmd) 기준입니다. 헷갈림을 줄이기 위해 딱 하나만 씁니다.
셀프 체크
STEP 1-2

Node.js를 설치합니다

클로드 코드가 달릴 도로를 먼저 깝니다. nodejs.org에서 LTS(왼쪽의 초록 버튼)를 내려받아, 계속 "다음"만 눌러 설치하세요.

설치가 끝나면 터미널을 완전히 껐다가 다시 열고, 아래를 붙여넣어 확인합니다.

확인
node -v
v22.14.0   ← 이렇게 v로 시작하는 숫자가 나오면 성공
셀프 체크
STEP 1-3

클로드 코드를 설치합니다

터미널에 아래 한 줄을 붙여넣고 Enter. 1~2분 정도 글자가 올라가면 정상입니다.

설치
npm install -g @anthropic-ai/claude-code
Mac에서 permission denied 오류가 나면 맨 앞에 sudo 를 붙여 다시 실행하고, 노트북 비밀번호를 입력하세요. (입력해도 화면엔 안 보이는 게 정상!)
셀프 체크
STEP 1-4

첫 실행과 로그인 — 여기가 제일 중요합니다

실행
claude

브라우저가 열리며 로그인을 요청합니다. 그리고 터미널에 선택지가 나타나요.

로그인 선택 화면
Select login method:
❯ 1. Claude account with subscription   ← 이걸 선택!
  2. Anthropic Console account            ← 선택 금지 (별도 요금 발생)
반드시 1번(구독 계정)을 선택하세요. 2번은 사용량만큼 카드에서 빠져나가는 별도 과금 방식입니다. 실수로 2번을 골랐다면 당황하지 말고 STEP 1-5에서 바로잡는 법을 따라오세요.
브라우저가 저절로 안 열리면, 터미널에 표시된 https://로 시작하는 주소를 복사해 브라우저 주소창에 직접 붙여넣으세요.
셀프 체크
STEP 1-5

제대로 로그인됐는지 검증합니다

클로드 코드 입력창에 아래를 입력해 보세요. (슬래시로 시작하는 건 클로드 코드의 자체 메뉴입니다)

검증
/status
Account: … Claude Pro/Max subscription 같은 표기가 보이면 ✓ 통과
"API" 라는 단어가 보이면 → /logout 입력 후 다시 로그인해서 1번 선택
셀프 체크

여기까지 됐다면 셋업데이 최소 목표는 달성입니다. 남은 캠프는 조금 더 편한 환경을 만드는 과정이에요.

VS Code — 클로드 코드의 작업실

10분소요
2스텝

터미널(검은 창)만으로도 클로드 코드를 쓸 수 있지만, VS Code를 쓰면 클로드가 만든 파일을 바로 보고, 수정 사항을 한눈에 확인할 수 있어요. 코드를 몰라도 "내 컴퓨터에서 무슨 일이 일어나고 있는지"가 눈에 보이니까 불안함이 줄어듭니다. 무료이고, 클로드 코드가 그 안에 들어갑니다.

STEP 3-1

VS Code를 설치합니다

code.visualstudio.com에서 큰 파란 버튼으로 내려받아 설치하세요. 모든 옵션은 기본값 그대로 "다음"이면 됩니다.

셀프 체크
STEP 3-2

확장 2개를 설치합니다

  1. 왼쪽 세로 아이콘 중 네모 블록 4개(확장 마켓)를 클릭
  2. 검색창에 Claude Code → Anthropic이 만든 것을 Install
  3. 검색창에 Korean → Korean Language Pack을 Install → 오른쪽 아래 안내가 뜨면 재시작

재시작하면 메뉴가 한국어로 바뀌고, 오른쪽 위(또는 왼쪽 사이드바)에 클로드 아이콘이 생깁니다.

셀프 체크

첫 과제 제출까지

12분소요
3스텝

이 캠프는 셋업데이 이후, 첫 과제가 나왔을 때 다시 와도 됩니다. 미리 읽어두면 "제출이 뭐지?"라는 불안이 사라져요.

STEP 5-1

과제 저장소를 컴퓨터로 가져옵니다

어렵게 들리지만, 클로드 코드에게 부탁하면 끝입니다. 공지에서 저장소 주소를 복사한 뒤:

이 저장소를 내 문서 폴더에 받아줘: [공지의 저장소 주소 붙여넣기]

받아진 폴더 안에 내 조 → 내 닉네임(본명) 폴더가 있고, 주차별 과제 폴더와 submission.md(제출 양식)가 들어 있습니다.

셀프 체크
STEP 5-2

제출 전에, 먼저 "풀"부터 받습니다

과제 우체통(레포)은 우리 기수 전원이 함께 씁니다. 그래서 내 것을 넣기 전에, 남들이 새로 넣은 걸 먼저 받아와야 꼬이지 않아요. 딱 두 단어만 기억하세요:

단어방향뜻
풀 Pull우체통 → 내 컴퓨터다른 크루가 올린 최신 내용을 받아오기
푸시 Push내 컴퓨터 → 우체통내가 쓴 과제를 올리기

순서는 언제나 풀 먼저, 푸시는 나중. 제출을 부탁하기 전에 이렇게 말해주세요:

제출하기 전에, 저장소 최신 내용부터 풀 받아줘
풀을 건너뛰고 올리면 "충돌(conflict)"이라는 안내가 뜰 수 있어요. 그래도 괜찮습니다 — 클로드 코드에게 "충돌 해결해줘"라고 말하면 됩니다.
셀프 체크
STEP 5-3

쓰고, 제출을 부탁합니다

  1. 해당 주차 폴더의 submission.md를 열고, 빈칸을 채웁니다 — 다 못 채워도 OK, 한 것 위주로!
  2. 스크린샷은 같은 폴더의 이미지첨부 폴더에 넣습니다
  3. 그리고 클로드 코드에게:
나는 N조 닉네임이야. 과제 제출해줘

제출 도우미(스킬)가 커밋부터 업로드까지 알아서 처리하고 결과를 알려줍니다. 브랜치니 PR이니 하는 말은 몰라도 됩니다.

제출이 잘 됐는지 궁금하면 깃허브 웹사이트에서 내 폴더를 열어보세요. 방금 쓴 내용이 보이면 성공입니다.

막혔을 때 — 여기가 진짜 비법입니다

7분소요
3스텝

"AI에게 물어보세요"라는 말, 처음엔 막막하죠. 그래서 그대로 복사해 쓰는 질문 문장을 준비했습니다. 지난 기수에서 막힘을 뚫은 실전 패턴들이에요.

STEP 6-1

복붙해서 쓰는 질문 5문장

① 에러가 떴을 때 — "지금 화면에 이런 에러가 떴어: [에러 붙여넣기]. 비개발자도 이해할 수 있게 설명해주고, 해결 순서를 한 단계씩 알려줘."
② 알려준 대로 했는데 안 될 때 — "네가 방금 알려준 방법이 안 됐어. 지금 화면에는 이렇게 보여: [상황 설명]. 다른 방법을 알려줘."
③ 용어가 어려울 때 — "이 용어를 초등학생도 알 수 있게 한 문장으로 설명해줘: [용어]"
④ 어디까지 왔는지 모르겠을 때 — "내가 하려는 것: [목표]. 지금까지 한 것: [상황]. 다음에 뭘 하면 되는지 순서대로 알려줘."
⑤ 겁이 날 때 — "지금부터 내가 하는 작업을 옆에서 지켜보다가, 위험한 것 같으면 실행 전에 꼭 나에게 확인해줘."

STEP 6-2

클로드 창을 하나 더 띄웁니다

지난 기수에서 의외로 몰랐던 꿀팁입니다. 클로드 코드가 터미널이나 VS Code에서 일하는 동안, 웹(claude.ai)이나 앱에서 클로드 창을 하나 더 열어두세요. 작업은 클로드 코드가, 질문은 옆 창의 클로드가 — 역할을 나누는 겁니다.

  • 모르는 용어가 나오면 → 옆 창에 물어보기 (작업 중인 클로드 코드를 방해하지 않아요)
  • 에러 화면이 뜨면 → 스크린샷을 찍어 옆 창에 붙여넣고 "이게 무슨 상황이야?" 물어보기
  • 뭘 시킬지 막막하면 → 옆 창에서 부탁할 문장을 먼저 다듬고, 완성되면 클로드 코드에 붙여넣기
같은 구독 계정으로 로그인하면 추가 요금 없이 둘 다 쓸 수 있습니다. 과외 선생님(클로드)과 작업 기사님(클로드 코드)을 동시에 두는 셈이에요.

STEP 6-3

사람을 부를 타이밍

AI로 안 풀리면 사람입니다. 스폰지클럽에는 무지성질문방이 있어요. 이름 그대로, 아무 질문이나 생각 없이 던져도 되는 방입니다. 부끄러운 질문이란 없습니다.

이 중 하나면 바로 조장을 불러주세요:

  • 같은 에러를 3번 넘게 반복하고 있을 때
  • 한 문제에 30분 넘게 막혀 있을 때
  • 로그인·결제·계정 관련일 때 (혼자 만지면 더 꼬여요)
지난 기수 크루의 말: "먼저 겪어본 사람들의 응원과 댓글로 헤쳐 나올 수 있었다." 질문은 민폐가 아니라 이 커뮤니티의 연료입니다.
